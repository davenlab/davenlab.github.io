Davenlab Uploader (YouTube API client)

"Davenlab Uploader" is a private, single-user software tool that uses YouTube API Services to manage the operator's own YouTube channels. It is not offered to the public and has no users other than the operator.

  • What it accesses: the operator's own channels only — uploading videos, setting thumbnails, managing playlists, and reading the operator's own channel analytics.
  • What it stores: OAuth tokens for the operator's own Google account, stored locally on the operator's computer. No viewer data, no third-party user data.
  • What it shares: nothing. Data is not sold, shared, or transferred to any third party.
  • Retention and revocation: tokens are deleted when the tool is retired. Access can be revoked at any time at Google Account → Security → Third-party access.

By using YouTube API Services, this tool is bound by the YouTube Terms of Service and the Google Privacy Policy.
